How it works

Audit, ask, remind, verify.

Each step is something you can see and check. Every number says which model produced it, and every answer shows the tools it used.

  1. 1

    Audit

    Drop in a CSV export. Gemma tidies the merchant names; TabPFN learns which charges recur and forecasts the next 30 days with a range, not a guess. Double charges, price creep and overlapping services get flagged.

  2. 2

    Ask

    “What if I cancel StreamFlix and WatchNest?” Ask Sloth answers with typed tools — including a live TabPFN forecast — and shows each call it made. It drafts refund and cancellation emails from your own charge history.

  3. 3

    Remind

    Pick a subscription and SlothSpend reminds you a few days before it renews — a desktop notification while the app is open, or the next time you open it. Keep it, snooze it, or cancel it yourself.

  4. 4

    Verify

    Said you cancelled? Import your next statement and SlothSpend checks the charge really stopped. If it didn’t, a refund request is ready to send.

Inform, never act.

  • It never cancels a subscription or logs in anywhere for you.
  • It never contacts a merchant or sends an email. It drafts; you send.
  • It never invents a link or a phone number — drafts are checked before you see them.
  • It never says it did something it didn’t — not even when the model wants to.

Why open models

Your bank data stays yours.

A year of transactions says where you live, what you eat and who you love. That only belongs on your own computer — and open models are what make a useful assistant possible there.

Gemma via Ollama

Gemma names, explains and drafts

Any Gemma model you have in Ollama. It cleans “ACH DEBIT IRONTRAP FITNESS MEMB 7731” into “IronTrap Fitness”, answers questions with tools, and writes notes and drafts — and code checks every number it writes against your data.

TabPFN v2 · open weights

TabPFN decides what recurs

A tabular foundation model that learns from a handful of examples in context. Mark one charge “not a subscription” and it re-scores in seconds. Add a free Prior Labs key to upgrade to TabPFN-3.5.

Download

Get started in a few minutes.

macOS (Apple Silicon)

Download .dmg

This hackathon build isn’t notarized. Drag SlothSpend to Applications, then right-click it and choose Open — or run xattr -cr /Applications/SlothSpend.app once.

Windows (x64)

Download .exe

The installer isn’t code-signed, so SmartScreen may warn you. Choose More info → Run anyway.

First run

  1. Install Ollama and open it.
  2. Any Gemma model works. If you have none, SlothSpend offers to download one.
  3. TabPFN v2 downloads automatically, once (about 70 MB, no account).
  4. Optional: paste a free Prior Labs key to upgrade to TabPFN-3.5 — a model licence, not an app login.
